# Student Marks Prediction using Machine Learning

## Project Overview
This project predicts a student's marks based on the number of hours studied using Machine Learning. A Linear Regression model is trained to learn the relationship between study hours and examination scores.
The model can estimate expected marks for a student based on the number of hours spent studying.

## Dataset
Custom Student Study Dataset

Features:
* Study Hours
Target:
* Marks Obtained
  
## Technologies Used
* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-Learn

## Machine Learning Workflow
1. Create and load dataset
2. Explore data
3. Split data into training and testing sets
4. Train Linear Regression model
5. Predict student marks
6. Evaluate model performance
7. Visualize results

## Machine Learning Concepts Used
* Supervised Learning
* Regression
* Linear Regression
* Train-Test Split
* Model Evaluation

## Features

* Data visualization using scatter plots
* Performance evaluation

* Actual vs Predicted comparison
